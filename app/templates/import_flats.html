Import Flats from Excel

Import multiple flats at once from an Excel file

Supported formats: .xlsx, .xls
Expected Excel Columns

Your Excel file should contain the following columns:

  • Flat No. - Flat number (required)
  • Payment Reference - Payment reference code
  • Tenancy / Property Address - Full property address (required)
  • Tenancy / Property Postcode - Postal code
  • Tenants - Tenant name(s)
  • Tenant Contact Details - Contact information
  • Rent - Monthly rent amount
  • Due Date - Day of month rent is due (1-31)
  • Tenancy Start Date - Tenancy start date
  • Tenancy End Date - Tenancy end date
  • Landlord - Landlord name
Cancel
Import Tips
Before Importing:
  • Ensure column names match exactly
  • Save Excel file as .xlsx format
  • Check for empty rows in your data
  • Verify flat numbers are unique
  • Make sure dates are in valid format
Import Process:
  • Existing flats will be updated
  • New flats will be created
  • Duplicate flat numbers merge data
  • Empty cells are ignored
After Import:
  • Review imported data for accuracy
  • Check any failed imports
  • Update missing information manually
